# Not Ready Project (Example)

This minimal repository intentionally omits key engineering artifacts so EARF can demonstrate failing outcomes. It is a generic placeholder project, not an AI application.

## What It Demonstrates

- A project can have a README but still fail critical/security/readiness checks
- Missing governance, workflow, and dependency evidence causes multiple rules to fail

## Expected EARF Status

Expected overall status: `NOT_READY`.

## Scan Command

Run from the repository root:

```bash
earf report examples/not-ready-ai-project
```
