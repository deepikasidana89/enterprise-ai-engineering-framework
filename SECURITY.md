# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities by opening a private security advisory in GitHub if available, or by contacting the maintainer directly.

Include:

- a clear description of the issue
- reproduction steps
- affected versions and environments
- potential impact

Please do not open public issues for unpatched vulnerabilities.

## Supported Versions

The latest release branch and the current development branch are supported on a best-effort basis.
