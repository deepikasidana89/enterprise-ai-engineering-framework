# EARF Pilot Registration Form

Use these questions to create a Google Form or another equivalent registration form.

## Questions

1. Full name
2. Email address
3. Job title or role
4. Organization, optional
5. Country or region, optional
6. What type of AI project would you like to assess?
   - AI assistant
   - RAG application
   - Agentic workflow
   - LLM API application
   - Evaluation or governance tool
   - Other
7. What language or framework does the project use?
8. Is the project public, private, academic, or personal?
9. What would you most like EARF to help you understand?
10. Are you willing to complete a 30–60 minute pilot and provide feedback?
11. May we contact you with follow-up questions?
12. Preferred attribution if your feedback is later approved for publication, optional

## Required privacy confirmation

> I confirm that I will use EARF only with a non-confidential repository or an approved local project. I will not submit source code, credentials, customer data, regulated data, or proprietary implementation details through the pilot form.
