# EARF Early Adopter Pilot

## Purpose

The EARF Early Adopter Pilot is a small, structured program to evaluate whether EARF helps independent engineers identify and prioritize production-readiness gaps in AI applications.

This is a feedback and validation program. It is not a certification program, security audit, compliance assessment, or endorsement.

## Who can participate

We are looking for engineers, technical leads, researchers, students, and AI platform or governance professionals working with:

- AI assistants
- RAG applications
- Agentic workflows
- LLM APIs
- Model-serving systems
- AI evaluation or governance tooling

Participants should use only a non-confidential repository. Do not submit source code, credentials, customer data, regulated data, or proprietary implementation details.

## What participation involves

The pilot takes approximately 30–60 minutes:

1. Choose a non-confidential AI repository.
2. Install EARF and run an assessment.
3. Review the generated report and evidence locations.
4. Validate a sample of the findings.
5. Optionally address one or two findings and rerun the assessment.
6. Complete the feedback form.
7. Optionally provide a testimonial or anonymous case study.

Participation is free. There is no employment relationship, commercial commitment, certification, or requirement to publish your feedback.

## What we will measure

- Installation and assessment time
- Report clarity and usability
- Finding accuracy
- Findings that were missed or incorrectly reported
- Whether EARF identified gaps not covered by an existing checklist
- Engineering changes made after the assessment
- Before-and-after readiness results
- Willingness to reuse or recommend EARF

## Participant workflow

| Stage | Participant action | Evidence collected |
|---|---|---|
| Registration | Complete the pilot form | Participant ID and project context |
| Baseline | Run EARF before changes | Original report and version |
| Review | Validate findings | Accuracy and gap feedback |
| Improvement | Fix selected gaps, if desired | Updated report and change summary |
| Exit | Complete feedback form | Ratings, comments, and consent |
| Publication | Approve wording, if desired | Testimonial or anonymized case study |

## Join the pilot

Complete the registration form or contact the EARF maintainer through the repository. Please include the type of AI project you would like to assess, but do not share confidential code or data.

## Attribution and privacy

Feedback will not be published with a participant's name, title, organization, or project details unless the participant gives explicit permission. Participants may choose anonymous attribution or may decline publication entirely.

## Feedback and contribution

Open a GitHub issue for reproducible bugs, false positives, false negatives, or missing framework patterns. Use a minimal non-confidential example whenever possible.
